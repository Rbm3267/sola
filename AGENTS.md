# SOLA FRAMEWORK ARCHITECTURE & AGENT SPECIFICATION (AGENTS.md)

This document provides exact syntax rules, AST schemas, control-flow specifications, and component library references for AI Coding Models (Claude, ChatGPT, Gemini, Antigravity) to author complete, production-ready Sola applications.

---

## 1. Core Framework Paradigm

Sola is a **zero-VDOM, fine-grained ambient runtime** (`~3.2 kB`).
- Components compile into **native JavaScript ES modules** that perform direct DOM node operations without virtual DOM diffing loops.
- Reactivity relies on fine-grained getter/setter signals (`createSignal`, `createDerived`, `createEffect`).

---

## 2. Component File Format (`.sola`)

A Sola component encapsulates logic (`<script>`), template markup (`HTML`), and scoped styling (`<style>`).

```html
<script>
  // Props received from parent host
  export let title = "Telemetry Monitor";
  export let initialCount = 0;

  // Local Reactive Signals ($state and $derived)
  let count = $state(initialCount);
  let doubled = $derived(count * 2);

  // Event Handlers
  function increment() {
    count += 1;
  }
</script>

<div class="card">
  <h3>{title}</h3>
  <p>Active Nodes: {count} (Capacity: {doubled})</p>
  <button onclick={increment}>Scale Node +1</button>
</div>

<style>
  .card {
    padding: 20px;
    background: #090d19;
    border-radius: 16px;
    color: #f8fafc;
  }
</style>
```

## 3. Template Control Flow & Expressions

### A. Conditionals (`{#if}`)
```html
{#if status === 'critical'}
  <div class="badge-red">CRITICAL INCIDENT</div>
{:else if status === 'warning'}
  <div class="badge-amber">WARNING TELEMETRY</div>
{:else}
  <div class="badge-emerald">SYSTEM NOMINAL</div>
{/if}
```

### B. Iteration Loops (`{#each}`)
```html
<ul>
  {#each items as item, index (item.id)}
    <li class="item-row">
      <span>{index + 1}. {item.name}</span>
      <button onclick={() => removeItem(item.id)}>Delete</button>
    </li>
  {/each}
</ul>
```

### C. Two-Way Form Inputs (`bind:value` or Event Handlers)
```html
<!-- Direct Signal Binding -->
<input type="text" value={searchQuery} oninput={(e) => searchQuery = e.target.value} placeholder="Filter incidents..." />
```

### D. Component Composition & Props
```html
<script>
  import DataCard from '@sola/ui/DataCard';
  import GaugeCard from '@sola/ui/GaugeCard';

  let rps = $state("1,420 RPS");
</script>

<div class="grid grid-cols-2 gap-4">
  <DataCard title="Cluster Volume" value={rps} trend="+14% vs baseline" icon="activity" />
  <GaugeCard title="CPU Saturation" percentage={78} subtext="12/16 Cores Active" color="amber" />
</div>
```

## 4. Signal Reactivity Primitives (@sola/core)

| Primitive | Signature | Purpose |
| :--- | :--- | :--- |
| `createSignal(initialVal)` | `[getter: () => T, setter: (v: T) => void]` | Creates a reactive state signal. |
| `createDerived(fn)` | `getter: () => T` | Computes a derived value, auto-tracking dependencies. |
| `createEffect(fn)` | `cleanupFn: () => void` | Runs a side-effect whenever dependent signals update. |
| `mount(el, props)` | `unmountFn: () => void` | Mounts component into native DOM node. |

## 5. Compiler Macro Primitives

### A. Dynamic Intent Generation (`$intent`)
Transpiles natural language requests into dynamic UI components generated by LLM synthesis.

```html
<script>
  // Transpiles to createIntent("Show cluster metric graphs")
  const analyticsWidget = $intent("Show cluster metric graphs");
</script>

<svelte:component this={analyticsWidget} />
```

### B. Remote Data Binding (`$data`)
Binds Google Sheets, ServiceNow, or PostgreSQL datasources with auto-polling.

```html
<script>
  // Binds live Google Sheet CSV or REST API endpoint
  const metrics = $data("sheet://1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms");
  const incidents = $data("/api/v1/servicenow/incidents");
</script>

<div>Active Volume: {metrics.volume}</div>
```

## 7. Host Embedding Rules (ServiceNow & React)

### A. ServiceNow Service Portal Widget
```javascript
function(c, $element) {
  var IncidentCard = window.SolaComponents.IncidentCard;
  var unmount = IncidentCard($element.find('#mount-root')[0], {
    sys_id: c.data.sys_id,
    priority: 'P1'
  });
  $scope.$on('$destroy', function() { if (unmount) unmount(); });
}
```

### B. React Wrapper Component (`useEffect`)
```jsx
import React, { useEffect, useRef } from 'react';
import MyWidget from './MyWidget.sola';

export function SolaReactHost({ props }) {
  const ref = useRef(null);
  useEffect(() => {
    const unmount = MyWidget(ref.current, props);
    return () => unmount();
  }, [props]);
  return <div ref={ref} />;
}
```
